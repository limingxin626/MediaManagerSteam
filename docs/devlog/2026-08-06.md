## Repository catalog 与 Scan 退役

- 用 `repository_folder` / `repository_file` 替换旧 `fs_entry`，空目录也可浏览；离线仓库或不完整遍历不会清除既有 catalog。
- watcher 自动监听在线 repository，新增物理文件后触发 debounce rescan；materializer 自动按 Blake2b hash 复用或创建 `Media` 并生成元数据、缩略图。
- 修复同路径内容覆盖仍挂旧 Media、Media FK 被清空后无法重新物化、扫描格式与 Media 支持格式不一致等状态问题。
- 删除 Vue Scan 页面、导航、专用组件及 `MediaPreview` 的 Scan-only 精简模式。
- 删除全部 legacy `/scan*` API、`FsEntry*` / `ScanStatusResponse` schema；Repository Browser 与 `/repositories*` 成为唯一物理仓库入口。
- 核心模块改为 repository 语义命名：`repository_catalog`、`repository_materializer`、`repository_watcher`、`repositories` router/schema。
- 相同内容的多个物理文件分别保留 catalog 行，但关联同一个去重后的逻辑 `Media`；因此文件夹/物理时间线可见多份，逻辑 Media 页面只显示一份。
